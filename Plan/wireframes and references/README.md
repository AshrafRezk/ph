# Wireframes and References

This folder holds wireframes, screenshots, and visual references for implementations documented in [`../BRD.md`](../BRD.md).

## Naming Convention

```
wireframe-{feature-slug}.png
```

Example: `wireframe-call-report.png` → linked as **WF-002** in the BRD.

## Adding a New Wireframe

1. Add the image file to this folder.
2. Register it in **Appendix A** of `BRD.md`.
3. Link it from the implementation section using a relative path.
4. Follow the rules in [`../general-rules-for-all-implementations.md`](../general-rules-for-all-implementations.md).
